# MeshView — STL / OBJ viewer with motion envelopes

Front-end only PWA (three.js r149). Drag & drop several STL / OBJ files and inspect them in a CAD-style 3D viewer: point / edge / face / object picking, distance measure, coordinate systems, section view, and reusable motions (Tx Ty Tz Rx Ry Rz) applied to meshes or whole files/groups, defined in any coordinate system (or at the barycentre), with their envelope drawn as one translucent object.

**Deploy on GitHub Pages:** push the content of this folder to the root of a repository, then *Settings → Pages → Deploy from a branch* (`main`, `/root`). Served over HTTPS, the app can be installed (button top right) and works offline.
